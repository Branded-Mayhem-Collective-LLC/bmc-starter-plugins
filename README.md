# BR8N and 8GNC useful starters
Four capabilities, eight separate host packages. BR8N AI Rescue and Workflow Test; 8GNC Brand Velocity Check and Website Enquiry Check. Each provides a complete first result and explicit next-test acceptance checks. No signup/email requirement, paid model API or direct booking CTA.

**Candidate source only. Hosted endpoints are proposed, not deployed or directory-approved.** Do not treat this repository as installation or delivery evidence. The existing 8gnc plugin remains separate.

`npm ci && npm run build && npm test`. UI uses the shared MCP Apps standard plus a narrow legacy OpenAI tool-output adapter. All results include Markdown text fallback. `npm run dev` serves the public candidate on loopback port 4361. Private assessment/retrieval/budget implementation is in a separate private repository; it is never bundled here.

See docs/privacy.md, docs/support.md, docs/portfolio.md, docs/website-integration.md, release/host-acceptance.md and each package's review/ folder. An installed host walkthrough, provider-secret injection, approved production runtime and Michael's acceptance precede directory submission. Claude's remote connector is a separate submission. Directory approval, publication, discovery and qualified demand are different milestones.
